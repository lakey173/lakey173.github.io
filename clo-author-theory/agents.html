Meet the Agents

18 specialized agents across 6 phases of theory research

Every creator has a paired critic. Critics score but never create. Creators produce but never self-score.

Researchers (Discovery Phase)

Librarian

Literature collector and organizer

Produces: Annotated bibliography, BibTeX entries, frontier map, positioning recommendation

Reviewed by: Librarian-Critic

Searches top-5 generals (AER, QJE, JPE, Econometrica, REStud), NBER, field journals, SSRN/RePEc. Assigns proximity scores (1–5) to each paper. Produces one-paragraph summaries. Never fabricates citations — marks unverified references.

Librarian-Critic

Reviews literature coverage

Reviews: Coverage, gaps, recency, journal quality, categorization

Deductions: Missing seminal papers (−20), no methods literature (−15), >50% working papers (−10), missing recent work (−10)

Literature-Explorer

Modeling landscape scout

Produces: Modeling landscape, proof technique catalog, benchmark model identification

Reviewed by: Literature-Explorer-Critic

The critical insight: online appendices contain the real proof machinery. Published papers show sketch proofs in the main text; the technical details (existence arguments, regularity conditions, comparative statics derivations) live in the appendix. The Literature-Explorer's job is to find these and document the techniques used.

Ends every run with a named prompt listing proximity-1/2 papers whose online appendices should be downloaded into master_supporting_docs/.

Literature-Explorer-Critic

Reviews modeling landscape

Reviews: Modeling landscape relevance, appendix coverage, benchmark identification, proof techniques

Deductions: Wrong benchmark (−25), appendices not examined (−20), seminal paper missing (−15)

Model Architect

Model-Designer Opus

Designs the complete model setup

Produces: Model memo (players, timing, payoffs, equilibrium concept, assumptions), benchmark comparison, tractability assessment

Reviewed by: Model-Critic

Checks master_supporting_docs/ for online appendices before starting. Proposes equilibrium concept with justification (Nash, PBE, BNE, dominant strategy, etc.). Lists all assumptions as A1, A2, ... with economic motivation. Maps to benchmark model: which parameter restriction collapses to the benchmark?

Model-Critic Opus

5-phase model evaluation

Reviews through 5 sequential phases (early stopping on fatal issues):

  1. Can the model answer the research question? (TRIAGE)
  2. Is the model setup sound? (Players, info structure, timing, payoffs)
  3. Is the model tractable? (Interior solution, existence, non-degenerate)
  4. Does it produce interesting results? (Testable predictions, economic meaning)
  5. Literature fit and generality? (Benchmark correct, not already done)

Deductions: Can't answer question (−40), already in literature (−30), inconsistent equilibrium concept (−25), implausible existence (−20)

Builders (Execution Phase)

Derivation-Engineer Opus

Formal mathematical proofs and derivations

Produces: LaTeX proofs in \begin{proof}...\end{proof} environments, derivation log

Reviewed by: Theory-Coder-Critic

Derives FOCs/SOCs, proves equilibrium existence and uniqueness, performs comparative statics. Every proof step cites the assumption that justifies it. Uses Implicit Function Theorem and Envelope Theorem where needed. Writes proofs with numbered steps for reference.

Theory-Coder Sonnet

Symbolic and numerical computation for verification

Produces: Verification scripts (Python/SymPy, Maple), numerical illustrations, publication-quality figures, verification log

Reviewed by: Theory-Coder-Critic

Four-stage workflow:

  • Stage 0: Symbolic verification (SymPy/Maple) — verify FOCs, solutions, comparative statics signs
  • Stage 1: Numerical illustrations — compute equilibrium across parameter grids
  • Stage 2: Publication figures (matplotlib) — serif fonts, no titles, colorblind-safe
  • Stage 3: Verification log — every proposition with analytical vs. numerical result

Theory-Coder-Critic (Shared Critic) Opus

Reviews both proofs and code for cross-consistency

This is the key architectural decision: one critic reviews both proofs and code. Its core job is checking consistency between formal proofs and computational verification. If the analytical comparative static says ∂x*/∂θ > 0 but the numerical computation shows the opposite, the theory-coder-critic catches it.

12 check categories spanning proof quality (4), code quality (5), and cross-consistency (3).

Deductions: Logical gaps (−35), code implements different model (−25), wrong SOC (−20), numerical contradicts analytical (−20)

Writer

Writer Sonnet

Drafts publication-quality manuscripts

Produces: Paper sections in LaTeX, appendix with formal proofs

Reviewed by: Writer-Critic

Theory paper structure: Introduction (contribution in first 2 pages) → [Related Work] → Model → Equilibrium Analysis → Comparative Statics → [Extensions] → Conclusion → Appendix.

Enforces: anti-hedging rules, \cref{} cross-references, \newcommand notation macros, proof sketch fidelity. Runs humanizer pass to strip 24 AI writing patterns.

Writer-Critic Sonnet

Reviews manuscript quality

Reviews: Structure, claims-evidence alignment, model fidelity, writing quality, grammar, LaTeX compilation

Deductions: Numbers don't match (−25), doesn't compile (−20), broken citations (−15), hedging (−5 each, max −15)

Reviewers (Peer Review Phase)

Editor

Manages simulated editorial process

Produces: Desk review decision, referee assignments (with dispositions), editorial decision

Desk-reviews for novelty and fit. Assigns two referees with different dispositions from a pool of 6:

  • Generality Hawk
  • Tractability Minimalist
  • Novelty Skeptic
  • Micro-Foundations Purist
  • Policy Oriented
  • Professional Skeptic

Synthesizes referee reports into own decision. Never averages scores — takes sides when referees disagree.

Domain-Referee

Blind reviewer — subject expertise

Produces: Independent referee report (5 dimensions + recommendation)

Calibrated by: domain-profile.md

Evaluates: Contribution & Novelty (30%), Literature Positioning (25%), Substantive Arguments (20%), External Validity (15%), Journal Fit (10%)

Theory-Referee Opus

Blind reviewer — mathematical rigor

Produces: Independent referee report (5 dimensions + recommendation)

Evaluates: Proof Correctness (35%), Assumptions & Equilibrium Concept (25%), Comparative Statics Robustness (20%), Generality (15%), Verification (5%)

Mandatory pre-scoring checks: Does the key proposition actually follow? Does equilibrium exist? Does the comparative static sign hold?

Presentation

Storyteller

Turns papers into talks

Produces: Beamer (.tex) or Quarto RevealJS (.qmd) presentations

Reviewed by: Storyteller-Critic

Designs narrative arc for 4 formats (job-market, seminar, short, lightning). One idea per slide, figures over tables, backup slides after \appendix.

Storyteller-Critic

Reviews talk quality Advisory

Reviews: Narrative flow, visual quality, content fidelity, scope for format, compilation

Score: Advisory (non-blocking) — reported but does not gate the pipeline.

Infrastructure

Orchestrator

Project manager coordinating all agents

Tracks dependency graph, dispatches worker-critic pairs, enforces quality gates, manages 3-strike escalation. Never produces research artifacts or scores work.

Verifier Sonnet

Compilation and mathematical structure inspector

Produces: Pass/fail verification report

Standard mode (5 checks): LaTeX compilation, theorem-proof pairing, cross-reference integrity, equation numbering, self-containedness.

Submission mode (10 checks): adds assumption coverage, proof sketch fidelity, notation consistency, bibliography integrity, appendix structure.
