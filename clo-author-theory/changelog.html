About Clo-Author Theory

An adaptation of clo-author for applied economic theory

What Is This?

Clo-Author Theory is an open-source Claude Code scaffold that manages the full lifecycle of an applied economic theory research project — from initial model design through formal proofs, computational verification, paper writing, simulated peer review, and journal submission.

It is an adaptation of Hugo Sant'Anna's clo-author, which was built for empirical economics research. While clo-author handles the empirical pipeline (data → cleaning → estimation → tables → paper), clo-author-theory handles the theory pipeline (model → proofs → comparative statics → verification → paper).

Both projects share the same multi-agent architecture: worker-critic pairs, quality scoring, escalation routing, and the plan-first workflow. The difference is in what the agents do.

Architecture at a Glance

  • 18 agents across 6 phases
  • 11 slash commands for the full pipeline
  • 7 rules files governing workflow, quality, and standards
  • 4 hooks for file protection and context survival
  • Worker-critic pairs with 3-strike escalation
  • Weighted quality scoring (6 components, submission requires ≥ 95)
  • Dependency-driven pipeline (phases activate by inputs, not sequence)
  • Two required gates: Online Appendix Gate + Sanity Check
  • Multi-model strategy: Opus for complex reasoning, Sonnet for speed
