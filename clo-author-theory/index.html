Clo-Author Theory

AI Research Architecture for Applied Economic Theory

An open-source Claude Code scaffold for applied economic theory research — from model design to journal submission. Adapted from Hugo Sant'Anna's clo-author (built for empirical research) to handle the distinct workflow of theory papers: formal proofs, equilibrium analysis, comparative statics, and mathematical verification.

Built on Hugo Sant'Anna's clo-author, itself built on Pedro Sant'Anna's claude-code-my-workflow, reoriented for applied theory publication.

You describe a task in plain English. Claude plans the approach (you approve), dispatches specialized agents, reviews quality, fixes issues, and presents results — 18 agents, 11 commands, all running behind the scenes. You review the output at each stage.

Get Started in 5 Minutes

Step 1: Fork & Clone

gh repo fork lakey173/clo-author-theory --clone
cd clo-author-theory

Step 2: Start Claude Code

claude

Using VS Code? Open the Claude Code panel instead.

Step 3: Paste the Starter Prompt

Fill in the bolded placeholders:

I am starting a new applied theory project in [YOUR FIELD] on [YOUR TOPIC]. Read CLAUDE.md and help me set up the project structure. Start with /discover interview [YOUR TOPIC].

Claude reads the configuration, fills in your project details, and enters contractor mode.

Step 4: Start Working

Once setup is done, describe what you need:

  • "Design a model for..." — designs players, timing, payoffs, equilibrium concept
  • /model signaling with moral hazard — formal model memo with tractability assessment
  • /solve — derives equilibrium, proves existence, computes comparative statics
  • /new-project trade policy under uncertainty — full pipeline from idea to paper

Day 1 Checklist

After forking:

  1. Fill in CLAUDE.md placeholders (project name, institution, field)
  2. Fill in domain-profile.md (field, target journals, notation conventions, seminal references) — or let /discover interview do it
  3. Test LaTeX compilation: cd paper && xelatex main.tex
  4. Test Python/SymPy: python scripts/python/test_sympy_workflow.py
  5. Run /discover interview [your topic] to start

What's Different from clo-author?

clo-author is built for empirical research (data cleaning, estimation, identification strategy). clo-author-theory replaces the empirical pipeline with a theory pipeline:

  • Strategist → Model-Designer — designs model setup instead of identification strategy
  • Data-engineer → Derivation-Engineer — formal proofs instead of data cleaning
  • Coder → Theory-Coder — symbolic/numerical verification instead of Stata/R estimation
  • Methods-referee → Theory-Referee — evaluates proofs and assumptions instead of causal inference
  • New: /sanity gate — validates model before expensive derivations
  • New: /solve command — parallel proofs + computation + cross-verification
  • Shared critic: theory-coder-critic reviews BOTH proofs and code for consistency

Origin

Clo-Author Theory adapts Hugo Sant'Anna's clo-author for applied economic theory. The original clo-author handles empirical workflows (data → estimation → tables). This fork handles theory workflows (model → proofs → comparative statics). Both share the same multi-agent architecture, quality scoring, and worker-critic pair design.
