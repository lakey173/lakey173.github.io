Command Reference

Complete reference for all 11 commands

/new-project

Full theory research pipeline from idea to paper.

/new-project [research topic or 'interactive']
AgentsAll (orchestrated through dependency graph)
OutputComplete pipeline: spec → literature → model → proofs → paper
BlockingYes (dependency gates at each phase)

Phases: Discovery → Model Design → Sanity Check → Execution → Writing → Review → Submission

The only command that is always orchestrated. Everything else can run standalone.

/discover

Discovery phase: research interviews, literature search, modeling landscape.

/discover interview [topic]    # Structured research interview
/discover lit [topic]          # Literature review
/discover model [topic]        # Modeling landscape exploration
/discover ideate [topic]       # Research ideation (3-5 questions)
Mode Agents Output
interviewDirect (conversational)Research spec + domain profile
litLibrarian → Librarian-CriticAnnotated bibliography, BibTeX, frontier map
modelLiterature-Explorer → Lit-Explorer-CriticModeling landscape, proof techniques, benchmark ID
ideateDirect3–5 research questions with model sketches

/model

Design the theoretical model setup.

/model [research question or spec path]
AgentsModel-Designer → Model-Critic
OutputModel memo, benchmark comparison, tractability assessment
Output locationquality_reports/model/[project]/
BlockingYes (score ≥ 80 required)

Model memo contents: players, timing, payoffs, equilibrium concept, assumptions (A1, A2, ...), benchmark model mapping, tractability plan, expected results.

Model-Critic 5-phase review:

  1. Can answer question?
  2. Sound setup?
  3. Tractable?
  4. Interesting results?
  5. Literature fit?

/sanity

Validate model before derivations. Required gate.

/sanity [model memo path or topic]
AgentsModel-Designer + Model-Critic (sanity mode)
OutputSanity report with PASS/FAIL
Output locationquality_reports/model/[project]/sanity_report.md
BlockingYes HARD GATE — must PASS before /solve

7 critical checks:

  1. Interior solution exists
  2. Non-degenerate equilibrium
  3. Non-knife-edge parameters
  4. Well-defined comparative statics
  5. Concavity/convexity verified
  6. Equilibrium existence plausible
  7. Non-trivial solution

Plus advisory: testable predictions exist.

/solve

Solve the model: proofs, computation, verification.

/solve [model memo path or topic]
/solve --symbolic-only          # Proofs only (closed-form known)
/solve --numeric-only           # Computation only (no closed form)
PrerequisitesModel memo approved (≥ 80) + Sanity PASS
AgentsDerivation-Engineer ∥ Theory-Coder + Theory-Coder-Critic
OutputAppendix proofs, verification scripts, figures, verification log
Output locationspaper/sections/appendix_proofs.tex, scripts/python/[project]/, paper/figures/, quality_reports/verification/[project]/
BlockingYes (score ≥ 80)

Required derivations: FOCs, equilibrium existence, characterization, comparative statics, welfare (if applicable).

/write

Draft paper sections with theory conventions.

/write intro [file]            # Introduction (contribution in first 2 pages)
/write model [file]            # Model section
/write equilibrium [file]      # Equilibrium analysis
/write results [file]          # Comparative statics / main results
/write conclusion [file]       # Conclusion
/write appendix [file]         # Appendix proofs
/write full [file]             # Complete paper
/write humanize [file]         # Strip AI writing patterns only
AgentsWriter → Writer-Critic
OutputLaTeX section files
Output locationpaper/sections/ or paper/main.tex
BlockingYes (depends on proofs being complete)

Enforced conventions: \cref{} cross-references, numbered assumptions, proof sketch fidelity, anti-hedging, humanizer pass.

/review

Quality reviews — routes to critics by file type and flags.

/review paper/main.tex                    # Comprehensive review
/review --peer [journal]                  # Full peer review
/review --peer --r2 [journal]             # R&R second round
/review --stress [journal]                # Hostile stress test
/review --proofs paper/sections/appendix_proofs.tex  # Proof review
/review --code scripts/python/verify.py   # Code review
/review --proofread                       # Manuscript polish
/review --all                             # All critics in parallel
Flag Agents Dispatched Score Type
(none, .tex)Writer-Critic + Theory-Coder-Critic + VerifierBlocking (≥ 80)
--peerEditor → Domain-Referee + Theory-Referee → Editorial decisionBlocking (editorial)
--stressBoth referees skeptic + 2 critical pet peevesBlocking
--proofsTheory-Coder-Critic (proof categories)Blocking (≥ 80)
--codeTheory-Coder-Critic (code categories)Blocking (≥ 80)
--proofreadWriter-Critic (6 categories)Blocking (≥ 80)
--allAll critics parallelBlocking (≥ 80)
(talk .tex)Storyteller-CriticAdvisory

/revise

R&R cycle: classify referee comments and route.

/revise [referee-report path] [paper path]
AgentsWriter, Theory-Coder (as needed)
OutputResponse letter, revision tracker, revised sections

Comment classifications:

Classification Routed To
NEW ANALYSISCoder
CLARIFICATIONWriter
DISAGREEUser
MINORWriter
Human in the loop

DISAGREE items are always flagged for human review. The system never autonomously pushes back on referees.

/talk

Create and manage presentations.

/talk create [format]          # Create talk (job-market|seminar|short|lightning)
/talk create [format] --quarto # Quarto RevealJS instead of Beamer
/talk audit [file]             # Visual audit
/talk compile [file]           # Compile (XeLaTeX or quarto render)
Format Slides Duration
job-market40–5045–60 min
seminar25–3530–45 min
short10–1515 min
lightning3–55 min
AgentsStoryteller → Storyteller-Critic
Outputpaper/talks/[format]_talk.tex or paper/quarto/[format]_talk.qmd
ScoreAdvisory (non-blocking)

/submit

Submission pipeline.

/submit target                 # Journal recommendations
/submit package                # Build replication package
/submit audit                  # Audit replication package
/submit final [journal]        # Final gate (≥ 95 + all ≥ 80)
Mode Output
targetJournal recommendations with rationale
packageReplication package in paper/replication/
audit10-point verification report
finalCover letter, submission checklist (if score passes)

Final gate: Aggregate score ≥ 95, every component ≥ 80. No exceptions.

/tools validate-bib            # Cross-reference citations vs. .bib
/tools journal                 # Regenerate research journal
/tools context                 # Show context usage
/tools deploy                  # Render and publish guide site
/tools learn                   # Extract session learnings
/tools upgrade                 # Upgrade infrastructure (preserves customizations)
