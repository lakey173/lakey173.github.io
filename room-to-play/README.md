# Room to Play — Knoxville feedback website

A standalone, interactive, mobile-friendly website summarizing **public feedback on the Knoxville Municipal Golf Course redevelopment**, with a youth-sports lens.

## Publish on GitHub Pages

1. Sign in to [GitHub](https://github.com/) and select **New repository**.
2. Name it `room-to-play` (or your preferred name), set visibility to **Public**, and create it.
3. Upload the contents of this folder to the **root** of the repository: `index.html`, `favicon.svg`, `.nojekyll`, and `README.md` (the last two are optional).
4. Commit the files.
5. Go to **Settings → Pages**, set **Build and deployment → Source** to **Deploy from a branch**; choose **main** and **/(root)**, then save.
6. After GitHub Pages finishes deploying, your site will generally be at `https://YOUR-USERNAME.github.io/room-to-play/` (replace the username and repo name).

To update the site later, edit or replace `index.html` in the repository and commit.

## Local preview

Double-click `index.html` to open it in your browser. No development tools, dependencies, API keys, or backend are needed.

## Editorial and attribution notes

- This is an **independent summary**, not a publication by Visit Knoxville, City of Knoxville, Knoxville Sports Authority, or One Knoxville SC.
- The visual palette is **inspired by local sporting colors**, without copying One Knox's official crest or logo.
- Survey questions have different sample sizes and multiple-choice selections may overlap. The site explains these limitations and links to the original feedback.
- Original source: https://www.visitknoxville.com/knox-sports-authority/knoxville-municipal-golf-course-redevelopment/public-feedback/
- Dataset reflects public results posted November 4, 2026; update manually if new results are published.
- GitHub Pages makes the files publicly visible; avoid adding confidential or private data.
